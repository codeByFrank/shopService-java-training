# ShopService

Ein einfaches Java-Projekt aus dem Neue-Fische-Bootcamp.  
Es dient zum Üben von Records, Listen und Repository-Klassen.

## Inhalt

- `Product`: enthält die Daten eines Produkts.
- `ProductRepo`: speichert und verwaltet Produkte.
- `Order`: enthält die Daten einer Bestellung.
- `OrderListRepo`: speichert und verwaltet Bestellungen.

## Bauen und testen

Das Projekt lässt sich im Projektordner mit Maven bauen und testen:

```bash
mvn clean verify
